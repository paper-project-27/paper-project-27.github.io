PP-CFG: Polarity-Preserving Guidance for Controllable Few-Step Image and Video Generation

Few-step diffusion students often lose adjustable classifier-free guidance and selectable negative prompts. PP-CFG keeps both prompt roles available at inference by conditioning them on guidance scale and denoising time, then combining their visual responses in one shared stream.

01 / Method

Separate prompt roles.
Share the visual stream.

At each denoising step, the Scale-Time Polarity Mixer refines positive and negative text conditions using the requested guidance scale and the current timestep. Polarity blocks combine the two attention responses before updating one visual state.

Scale and denoising time share one conditioning sequenceHg,t = Hg + Ht
Positive and negative visual responses meet inside the blockΔH = ΔH+ − λΔH−

The negative response is subtracted at the attention-feature level. The mixer receives the runtime guidance scale g; λ weights the negative attention response and has a different role. The two prompt paths add computation beyond an unguided pass.

03 / Benchmark and examples

Matched image and video cases.

NegElement-1K tests whether a specified element disappears while a related scene is generated in either modality.

NegElement-1K

Each template-generated case pairs an image prompt and a video prompt for the same scene with a negative prompt naming the target. Annotations also identify three scene elements to preserve, target position, size, and difficulty. A Qwen3.5-VL judge checks target presence; failed or unparseable judgments count as failures.
